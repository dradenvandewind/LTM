Calculate the MD5sum of pic, storing the result in digest. \doxylink{classMD5}{MD5} calculation is performed on Y\textquotesingle{} then Cb, then Cr; each in raster order. Pel data is inserted into the \doxylink{classMD5}{MD5} function in little-\/endian byte order, using sufficient bytes to represent the picture bitdepth. Eg, 10bit data uses little-\/endian two byte words; 8bit data uses single byte words.
