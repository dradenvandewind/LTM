{\footnotesize\ttfamily uint32\+\_\+t calc\+MD5 (\begin{DoxyParamCaption}\item[{const CPel\+Unit\+Buf \&}]{pic,  }\item[{Picture\+Hash \&}]{digest,  }\item[{const Bit\+Depths \&}]{bit\+Depths }\end{DoxyParamCaption})}

Calculate the MD5sum of pic, storing the result in digest. \doxyref{MD5}{p.}{classMD5} calculation is performed on Y\textquotesingle{} then Cb, then Cr; each in raster order. Pel data is inserted into the \doxyref{MD5}{p.}{classMD5} function in little-\/endian byte order, using sufficient bytes to represent the picture bitdepth. Eg, 10bit data uses little-\/endian two byte words; 8bit data uses single byte words.
