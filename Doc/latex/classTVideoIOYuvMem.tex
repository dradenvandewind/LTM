open or create file 

Open file for reading/writing Y\textquotesingle{}Cb\+Cr frames.

Frames read/written have bitdepth file\+Bit\+Depth, and are automatically formatted as 8 or 16 bit word values (see \doxyref{TVideo\+IOYuv\+Mem\+::write()}{p.}{classTVideoIOYuvMem_aa8bd6bc7e05ebf0f4f19708964937b96}).

Image data read or written is converted to/from internal\+Bit\+Depth (See scale\+Plane(), \doxyref{TVideo\+IOYuv\+Mem\+::read()}{p.}{classTVideoIOYuvMem_a2425cbccbaef0117b081dafc41c21077} and \doxyref{TVideo\+IOYuv\+Mem\+::write()}{p.}{classTVideoIOYuvMem_aa8bd6bc7e05ebf0f4f19708964937b96} for further details).

read one frame with padding parameter 

Read one Y\textquotesingle{}Cb\+Cr frame, performing any required input scaling to change from the bitdepth of the input file to the internal bit-\/depth.

If a bit-\/depth reduction is required, and internal\+Bitdepth $>$= 8, then the input file is assumed to be ITU-\/R BT.\+601/709 compliant, and the resulting data is clipped to the appropriate legal range, as if the file had been provided at the lower-\/bitdepth compliant to Rec601/709.
