The {\itshape cross\+\_\+checking\+\_\+tools} folder on the MPEG FTP server contains the following content\+:
\begin{DoxyItemize}
\item \doxylink{stresstest_8py}{stresstest.\+py} -\/ The python script to perform the tests with
\item tests.\+json -\/ A json file which contains the settings for the individual tests
\item main\+\_\+profile.\+json -\/ A json file in which parameters are set which are shared between all tests in the test-\/set
\item input\+\_\+yuvs -\/ Folder with the YUV input files
\end{DoxyItemize}\hypertarget{md__2media_2erwan_2T7_2formation_2Video_2LTM_2stress__tests_2README_autotoc_md28}{}\doxysection{\texorpdfstring{Test Set-\/\+Up}{Test Set-Up}}\label{md__2media_2erwan_2T7_2formation_2Video_2LTM_2stress__tests_2README_autotoc_md28}

Most of the tests can be run automatically without any additional input. The python script \doxylink{stresstest_8py}{stresstest.\+py} can be used to perform the encodes and decodes. Additionally, the reconstruction yuv file of the encoder and the yuv of the decoder are checked whether they are matching. In case, multiple cores are available to perform the tests, the following command lines can be appended by the argument

\hypertarget{md__2media_2erwan_2T7_2formation_2Video_2LTM_2stress__tests_2README_autotoc_md32}{}\doxysubsection{\texorpdfstring{Special Tests}{Special Tests}}\label{md__2media_2erwan_2T7_2formation_2Video_2LTM_2stress__tests_2README_autotoc_md32}
Some tests cannot be performed automatically and need manual input.


\begin{DoxyItemize}
\item For Cactus \& Can\+You\+Read\+This, the tests "{}\+RBD-\/1"{} and "{}\+RBD-\/2"{} require as an input the 10 bit yuv file (provided in the folder inputs\+\_\+yuv). Additionally, the format needs to be changed to "{}yuv420p10"{}. These tests can be run by specifying 
\begin{DoxyCode}{0}
\DoxyCodeLine{-\/-\/sets="{}stress\_10bit"{}}

\end{DoxyCode}
 on the command line of the python script.
\item The tests "{}\+RBD-\/3 and RBD-\/4"{} require as an input the 12 bit yuv file (provided in the folder inputs\+\_\+yuv). Additionally, the format needs to be changed to "{}yuv420p12"{}. These tests can be run by specifying 
\begin{DoxyCode}{0}
\DoxyCodeLine{-\/-\/sets="{}stress\_12bit"{}}

\end{DoxyCode}
 on the command line of the python script.
\item The test "{}\+CST-\/1"{} require as an input a monochrome yuv file (4\+:0\+:0) (provided in the folder inputs\+\_\+yuv). Additionally, the format needs to be changed to "{}y"{} for Cactus \& Can\+You\+Read\+This and to "{}y10"{} for Park\+Running3. The test can be run by specifying 
\begin{DoxyCode}{0}
\DoxyCodeLine{-\/-\/sets="{}stress\_mono"{}}

\end{DoxyCode}
 on the command line of the python script.
\item For the tests "{}\+HDUD-\/1"{} through "{}\+HDUD-\/4"{}, the user data must be extracted. This can be done by compiling the LCEVC Test Model (LTM) with "{}\+USER\+\_\+\+DATA\+\_\+\+EXTRACTION"{} (located in \doxylink{Config_8hpp}{src/\+Config.\+hpp}) turned on. The user data from the encoder and decoder will be written into a binary file. These files can be cross-\/checked with the files provided on the MPEG FTP server.
\end{DoxyItemize}\hypertarget{md__2media_2erwan_2T7_2formation_2Video_2LTM_2stress__tests_2README_autotoc_md33}{}\doxysection{\texorpdfstring{Providing the Results}{Providing the Results}}\label{md__2media_2erwan_2T7_2formation_2Video_2LTM_2stress__tests_2README_autotoc_md33}
In order to track the cross-\/checking results, the provided Excel spreadsheet on the MPEG FTP server can be used. The corresponding columns for the cross-\/checking can be updated and the modified file can afterwards be uploaded to the FTP server.
