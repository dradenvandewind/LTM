\DoxyCodeLine{}
\DoxyCodeLine{This\ will\ take:}
\DoxyCodeLine{\ \ -\/\ A\ source\ video\ in\ raw\ YUV\ 420\ format,\ either\ 8\ bpp\ or\ 10\ bpp,\ }
\DoxyCodeLine{\ \ -\/\ A\ base\ format\ elementary\ stream,\ either\ AVC,\ HEVC,\ EVC\ or\ VVC,\ }
\DoxyCodeLine{\ \ -\/\ The\ reconstructed\ base\ video\ YUV,\ }
\DoxyCodeLine{\ \ -\/\ A\ description\ of\ video\ format,\ }
\DoxyCodeLine{\ \ -\/\ A\ choice\ of\ the\ base\ format,\ }
\DoxyCodeLine{\ \ -\/\ Optionally,\ a\ configuration\ file\ for\ the\ encoder,\ e.g.\ config.json\ }
\DoxyCodeLine{}
\DoxyCodeLine{Please\ note\ that\ the\ base\ encoder\ or\ decoder\ (AVC,\ HEVC,\ EVC\ or\ VVC)\ may\ be\ called\ by\ the\ LTM\ Encoder\ to\ construct\ the\ base\ encoded\ bitstream\ as\ well\ as\ the\ corresponding\ YUV\ sequence.<br>}
\DoxyCodeLine{Thus,\ it\ is\ essential\ to\ have\ the\ \`{}external\_codecs`\ folder\ copied\ in\ the\ working\ directory.}
\DoxyCodeLine{}
\DoxyCodeLine{In\ case\ the\ option\ \`{}-\/-\/parameter\_config=default`\ is\ used,\ some\ of\ the\ parameter\ values\ will\ be\ derived\ from\ the\ input\ step\ width\ of\ enhancement\ sub-\/layer\ 2.\ To\ disable\ this\ feature,\ please\ use\ \`{}-\/-\/parameter\_config=conformance`.}
\DoxyCodeLine{}
\DoxyCodeLine{There\ are\ three\ possible\ modes\ of\ operation\ of\ the\ LTM\ Encoder,\ depending\ on\ the\ input\ sequence\ provided:}
\DoxyCodeLine{\ \ -\/\ using\ as\ input\ an\ original\ YUV\ sequence,\ the\ Encoder\ will\ first\ invoke\ the\ "{}external\ base\ encoder\ (AVC,\ HEVC,\ EVC\ or\ VVC)"{}\ to\ produce\ the\ base\ bitstream\ and\ the\ corresponding\ YUV\ reconstruction.}

\DoxyCodeLine{\ \ -\/\ using\ as\ input\ an\ already\ encoded\ base,\ without\ the\ corresponding\ YUV,\ the\ Encoder\ will\ first\ invoke\ the\ "{}external\ base\ decoder\ (AVC,\ HEVC,\ EVC\ or\ VVC)"{}\ to\ produce\ the\ corresponding\ YUV\ reconstruction.}
\DoxyCodeLine{then,\ the\ LTM\ Encoder\ will\ use\ such\ base\ bitstream\ plus\ YUV\ sequence\ for\ its\ operation;}
\DoxyCodeLine{\ \ -\/\ using\ as\ input\ an\ already\ encoded\ AVC,\ HEVC,\ EVC\ or\ VVC\ base,\ with\ the\ corresponding\ YUV,\ }
