\doxysubsection{Detailed Description}
An \doxylink{classAccessUnit}{Access\+Unit} is a list of one or more NAL units, according to the working draft. All NAL units within the object belong to the same access unit.

NALUnits held in the \doxylink{classAccessUnit}{Access\+Unit} list are in EBSP format. Attempting to insert an Output\+NALUnit into the access unit will automatically cause the nalunit to have its headers written and anti-\/emulation performed.

The \doxylink{classAccessUnit}{Access\+Unit} owns all pointers stored within. Destroying the \doxylink{classAccessUnit}{Access\+Unit} will delete all contained objects.
