\doxysubsection{Detailed Description}
An \doxyref{Access\+Unit}{p.}{classAccessUnit} is a list of one or more NAL units, according to the working draft. All NAL units within the object belong to the same access unit.

NALUnits held in the \doxyref{Access\+Unit}{p.}{classAccessUnit} list are in EBSP format. Attempting to insert an Output\+NALUnit into the access unit will automatically cause the nalunit to have its headers written and anti-\/emulation performed.

The \doxyref{Access\+Unit}{p.}{classAccessUnit} owns all pointers stored within. Destroying the \doxyref{Access\+Unit}{p.}{classAccessUnit} will delete all contained objects.
